Vercel alternative

A Vercel alternative with the backend included

Berth hosts your static site or front end with preview links, instant rollbacks, redirects and custom domains with HTTPS, and it gives the same app a Postgres database, sign in, storage and functions.

What is the same

  • Deploy a build folder. berth sites deploy ./dist uploads only changed files and switches over at once.
  • Previews and rollbacks. Every deploy gets a preview link, and you can roll back in one command.
  • Custom domains with automatic HTTPS.

What is different

  • The backend is built in. Vercel offers databases and auth through Marketplace partners. On Berth every app has its own Postgres database, sign in and storage.
  • Commercial use on the free plan. Vercel's Hobby plan is for personal, non-commercial use. Berth's free plan has no such rule.
  • No usage bill. Vercel bills usage beyond what a plan includes. Berth's limits are hard caps.
  • Where Vercel is stronger: server rendering and a worldwide edge network. Berth serves static sites and runs functions in the United States.
