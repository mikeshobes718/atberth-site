Platform

What you get.
A place to run it.

You pay Berth to host the app or site. That berth includes a database, an API, HTTPS, and a backup every night.

Postgres 17

The database for your app. Real Postgres on the server, reachable only from inside it.

  • Postgres 17
  • Private network only
  • Backed up every night
pg 17

Always on

Your app runs on a server that stays up. Berth looks after the machine.

  • Server stays up
  • Berth runs it for you

PostgREST

Your tables become REST endpoints. The API follows the database schema.

GET https://api.atberth.com/...
Authorization: Bearer $TOKEN

Deno API

Server logic in TypeScript, in front of your database, behind HTTPS.

  • HTTPS at api.atberth.com
  • TypeScript on Deno

Token required

Every request to the API carries a token. No token, no data. The database itself has no public door.

  • Token on every request
  • Database not on the internet

How it works

Request a berth.
We host the app.

No public signup. You write, Berth sets up the database, the API, and HTTPS, and your app runs there.

  1. 1

    Request

    Tell us the app or site you want hosted. Pricing comes back with the reply.

  2. 2

    Set up

    Berth prepares a database, an API, and HTTPS for it.

  3. 3

    Connect

    Your app calls the API over HTTPS. Every request carries a token.

  4. 4

    Keep

    Backups run every night. The database stays off the public internet.
